STEP 2.6: analysis/profiling.py (Dataset Health & Audit)
--------------------------------------------------------------------------------
Create and implement 'analysis/profiling.py' with the following pure functions:

1. calculate_health_score(df: pd.DataFrame) -> dict
   - Purpose: Composite quality score (0 - 100) and letter grade rating data hygiene.
   - Deduction Rules:
     * Missing values: Deduct up to -30 points proportional to global missing %:
       - min(30.0, round(missing_pct * 1.5, 1))
     * Duplicate rows: Deduct up to -20 points proportional to duplicate row %:
       - min(20.0, round(duplicate_pct * 2.0, 1))
     * Outlier presence: Deduct up to -20 points based on % of numeric columns with severe outliers (>5% outlier rate):
       - min(20.0, round((cols_with_outliers / total_num_cols) * 20.0, 1))
     * Constant / Zero-variance columns: Deduct up to -15 points:
       - min(15.0, constant_cols_count * 5.0)
   - Final Score:
     * score = max(0.0, min(100.0, round(100.0 - total_deductions, 1)))
   - Letter Grade Mapping:
     * A: 90 - 100
     * B: 80 - 89
     * C: 70 - 79
     * D: 60 - 69
     * F: < 60
   - Returns dict:
     {
         "health_score": float,
         "grade": str,
         "deductions": {
             "missing": float,
             "duplicates": float,
             "outliers": float,
             "constant_cols": float
         },
         "summary": str
     }

2. generate_dataset_audit(df: pd.DataFrame) -> dict
   - Purpose: Comprehensive master diagnostic audit combining all core analysis engines into a single dashboard-ready report.
   - Aggregates:
     * Dataset Shape & Memory: rows, columns, memory usage (bytes & formatted MB).
     * Data Types Breakdown: count of numeric, categorical, datetime, boolean columns.
     * Missingness Overview: total missing cells, overall missing %, columns with missing values.
     * Duplicate Overview: duplicate row count, duplicate %.
     * Outlier Overview: count of numeric columns with outliers, top outlier columns.
     * Health Score & Grade: output of calculate_health_score(df).
     * Actionable Warnings (list of string alerts for user):
       - E.g.: "High missing data (>30%) in column: 'Age'"
       - E.g.: "Found 150 duplicate rows (5.2% of dataset)"
       - E.g.: "Column 'User_ID' is constant/zero-variance"
       - E.g.: "High multicollinearity detected between 'Income' and 'Net_Worth'"
   - Returns dict:
     Structured dictionary ready for UI cards, audit tabs, and executive summaries.
