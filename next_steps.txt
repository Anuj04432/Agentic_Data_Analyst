--------------------------------------------------------------------------------
STEP 2.2: analysis/missing_values.py
--------------------------------------------------------------------------------
Functions to implement:

1. get_missing_summary(df: pd.DataFrame) -> pd.DataFrame
   - Purpose: Per-column missing value breakdown.
   - Output columns: ["Column", "Data Type", "Total Rows", "Missing Count", "Missing %", "Has Missing"]
   - Sort: Descending by "Missing %".
   - Edge case: return pd.DataFrame() if df is None or empty.

2. get_missingness_overview(df: pd.DataFrame) -> dict
   - Purpose: High-level KPI metrics for top summary cards.
   - Returns dict:
     {
         "total_missing_cells": int,
         "total_cells": int (rows * cols),
         "overall_missing_pct": float (round to 2 decimals),
         "columns_with_missing_count": int,
         "columns_with_missing": list[str]
     }

3. impute_missing_values(df: pd.DataFrame, strategy: str = "auto", custom_values: dict = None) -> pd.DataFrame
   - Purpose: Clean / fill missing values on a copy (df.copy()).
   - Strategies supported:
     * "mean": numeric columns filled with mean
     * "median": numeric columns filled with median
     * "mode": all columns filled with mode (mode().iloc[0])
     * "drop_rows": df.dropna()
     * "drop_cols": df.dropna(axis=1)
     * "auto": numeric -> median, categorical/text -> mode
     * custom_values: if provided, use df.fillna(custom_values)

STEP 2.3: analysis/duplicates.py
--------------------------------------------------------------------------------
Functions to implement:

1. get_duplicate_summary(df: pd.DataFrame, subset: list[str] = None) -> dict
   - Purpose: Summary of duplicate rows in dataset.
   - Returns dict:

         "duplicate_count": int,

     }

2. drop_duplicates_clean(df: pd.DataFrame, subset: list[str] = None, keep: str = "first") -> tuple[pd.DataFrame, int]
   - Purpose: Remove duplicate rows safely on a copy.
   - Returns: (cleaned_df, removed_count)


--------------------------------------------------------------------------------
STEP 2.4: analysis/correlations.py
--------------------------------------------------------------------------------
Functions to implement:

1. get_correlation_matrix(df: pd.DataFrame, method: str = "pearson") -> pd.DataFrame
   - Purpose: Numeric correlation matrix (support "pearson" and "spearman").
   - Edge case: If numeric columns < 2, return empty DataFrame.

2. get_top_correlations(df: pd.DataFrame, threshold: float = 0.5, top_n: int = 10, method: str = "pearson") -> pd.DataFrame
   - Purpose: Find highest correlated pairs across the dataset.
   - Output columns: ["Feature 1", "Feature 2", "Correlation", "Absolute Correlation", "Direction"]
   - Sorted descending by "Absolute Correlation".

3. get_target_correlations(df: pd.DataFrame, target_col: str, method: str = "pearson") -> pd.DataFrame
   - Purpose: Rank all numeric features by correlation with a specific target column.
   - Output columns: ["Feature", "Correlation", "Absolute Correlation"]


--------------------------------------------------------------------------------
STEP 2.5: analysis/outliers.py
--------------------------------------------------------------------------------
Functions to implement:

1. detect_outliers_iqr(series: pd.Series, factor: float = 1.5) -> dict
   - Calculates Q1, Q3, IQR, lower_bound = Q1 - factor*IQR, upper_bound = Q3 + factor*IQR.
   - Returns bounds, outlier count, outlier %, and boolean mask / indices.

2. detect_outliers_zscore(series: pd.Series, threshold: float = 3.0) -> dict
   - Calculates z-scores = abs((x - mean) / std).
   - Returns outlier count, outlier %, and indices where z > threshold.

3. get_outliers_summary(df: pd.DataFrame, method: str = "iqr") -> pd.DataFrame
   - Table of all numeric columns summarizing:
     ["Column", "Outlier Count", "Outlier %", "Lower Bound", "Upper Bound", "Min", "Max"]

4. cap_outliers(df: pd.DataFrame, col: str, factor: float = 1.5) -> pd.DataFrame
   - Winsorize / cap values exceeding bounds to lower_bound and upper_bound.


--------------------------------------------------------------------------------
STEP 2.6: analysis/profiling.py
--------------------------------------------------------------------------------
Functions to implement:

1. calculate_health_score(df: pd.DataFrame) -> dict
   - Composite quality score (0 - 100):
     * Deductions for missing cells (up to -30 pts)
     * Deductions for duplicate rows (up to -20 pts)
     * Deductions for heavy outlier columns (up to -20 pts)
     * Deductions for zero-variance / constant columns (up to -15 pts)
   - Assign letter grade: A (90-100), B (80-89), C (70-79), D (60-69), F (<60).

2. generate_dataset_audit(df: pd.DataFrame) -> dict
   - Master report combining shape, memory, missingness, duplicates, outliers, and list of actionable warning messages.
